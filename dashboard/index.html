The watchlist is the floor: every protocol with at least $50M of TVL and no token on record. The early radar adds 138 pre-token protocols below that floor and 20 above it that the list leaves out. Implied value is a model, not a promise.

Implied value = TVL × fitted multiple (the value if a token launches) × token odds (from how long peers ran before recording one). Each coefficient is fitted on this snapshot and tested held-out.
